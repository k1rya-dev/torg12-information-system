**Год:** 2025

---

## Описание проекта

Разработана информационная система для автоматизации работы с товарными накладными ТОРГ-12. Система предназначена для бухгалтеров, кладовщиков, товароведов и менеджеров по продажам, позволяя создавать, редактировать, печатать и выгружать накладные в форматах DOCX и XML.

---

## Выполненные задачи

1. Анализ предметной области и нормативно-правовой базы (ГК РФ, НК РФ, 402-ФЗ, Постановление Госкомстата №132)
2. Разработка диаграммы вариантов использования (Use Case)
3. Проектирование модульной архитектуры системы
4. Создание даталогической модели базы данных (5 таблиц)
5. Разработка алгоритма формирования накладной
6. Реализация приложения на Python с использованием Tkinter
7. Создание экранных форм и интерфейса пользователя
8. Реализация форматно-логического контроля данных
9. Интеграция с XML-файлами договоров и накладных
10. Генерация отчетов и печатных форм

---

## Функциональные возможности

- Создание и редактирование товарных накладных
- Ведение справочников товаров, контрагентов и договоров
- Импорт данных из CSV и XML
- Экспорт накладных в XML (формат ФНС)
- Печать накладных в формате DOCX
- Генерация отчетов по накладным за период
- Редактирование статуса накладной
- Форматно-логический контроль с подсветкой ошибок

## Технологический стек

| Компонент | Технология |
|-----------|------------|
| Язык программирования | Python 3 |
| GUI-фреймворк | Tkinter |
| Работа с Excel | OpenPyXL |
| Парсинг XML | xml.etree.ElementTree |
| Данные | CSV-файлы |
| Печатная форма | DOCX (через XLSX-шаблон) |

## Структура данных

| Файл | Содержание |
|------|------------|
| `products.csv` | Справочник товаров |
| `buyers.csv` | Справочник контрагентов |
| `deals.csv` | Договоры с контрагентами |
| `invoices.csv` | Заголовки накладных |
| `invoices_items.csv` | Позиции накладных |
